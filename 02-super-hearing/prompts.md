# 02 · Super Hearing — prompts

**Context:** You joined Rook two weeks ago as PM on Dispatch.
Release 4.2 shipped on 12 August, just before you arrived, and
landed badly. Last session you built a context file and met the
company.

You still do not know what actually went wrong.

At the end of the session, ask Claude Code to save the prompts you
wrote yourself below — not the starter prompt. The closing slide has
the exact prompt to paste. By Module 6 this file is a prompt library
built from your own questions.

---

### 1.

Where are the problem ticketS? Where are interviews with customers? Add these to CLAUDE.md so you can easily find them

### 2.

Read through the interviews. List out key insights from these interviews, group them, count how many people mentioned these and quote one line for each so I can hear how they actually say it.

### 3.

Are any of these interviews  contradict what's in another one?

### 4.

What would you do to make sure that the insights you're basing on make sure

### 5.

Prioritize the insights based on your assessment of their severity as well as the contradictions across interviews

### 6.

Did the questions for all of these interviews looked the same or was there something different about them?

### 7.

Adjust the table and then flag which of these issues may be related to 4.2 patch

### 8.

Now look into tickets. Analyze which of them were submitted before and which after 4.2 landed. Find out what tickets say, group the insights, count their appearance and quote one line from each.

### 9.

It looks like the topics reflect the findings from the interviews. Is there actually some difference?

### 10.

Now combine insights from tickets and interviews, clearly list out the issues with 4.2.

### 11.

Make it MECE

### 12.

Are those people who report not receiving calls, actually receiving and accepting or declining them, or just receiving and not seeing them apparently

### 13.

List out all the responders in the table and compare average weekly sent and taken pings from before and after 4.2. Also, mark which of these report not receiving calls after 4.2

### 14.
